## 📱 INSTALL WITH TERMUX :

```bash
pkg update -y && pkg upgrade -y -o Dpkg::Options::="--force-confold" && for p in curl git ncurses-utils jq python; do command -v $p >/dev/null 2>&1 || pkg install -y $p; done && git clone https://github.com/Syedkashaf2/CODEX.git && cd CODEX && bash install.sh
```

---

### 🐧 INSTALL WITH LINUX:

```bash
sudo apt update -y && sudo apt upgrade -y && for p in curl git ncurses-utils jq python3; do command -v $p >/dev/null 2>&1 || sudo apt-get install -y $p; done && git clone https://github.com/Syedkashaf2/CODEX.git && cd CODEX && bash install.sh
```

---

### 📥 INSTALL WITH CURL:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Syedkashaf2/CODEX/main/install.sh)
```

<details id="advanced-usage">

  <summary>📚 ADVANCED USAGE GUIDE</summary>

### Theme Customization

```bash
# List all themes
themes -l

# Apply theme
themes apply dark-matrix

# Create custom theme
themes create "my-theme"
```

### System Monitoring

```bash
# Real-time dashboard
monitor

# CPU stats
monitor cpu

# Memory stats
monitor memory

# Network stats
monitor network
```

### Git Integration

```bash
# Quick commit
gitx commit "message"

# Clone and setup
gitx clone-setup <repo-url>

# Status with dashboard
gitx status-full
```

### Session Management

```bash
# Backup session
backup create session-name

# Restore session
backup restore session-name

# List backups
backup list
```

### Alias Management

```bash
# Add alias
alias add ll="ls -lah"

# Remove alias
alias remove ll

# List all
alias list

# Export aliases
alias export > my-aliases.conf
```

### Configuration

```bash
# Edit config
config edit

# Reset to defaults
config reset

# Validate config
config validate

# Sync config across devices
config sync
```
